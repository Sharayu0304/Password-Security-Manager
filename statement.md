## THE PROBLEM DESCRIPTION
The problem deals with the maintenance of multiple passwords for different websites. Many people tend to forget the strength of their passwords. It is a Java program that requires a user's details and website passwords. This paper will discuss a program that evaluates the type of password, strength, and length while storing the details in a text file.

## WHAT THIS PROJECT WILL ACCOMPLISH
The project will be an application that manages passwords by using Java. This program will require a person's name and email address and the website name and password. It will involve checking the password's strength, moderate, and poor levels. The application will also check the passwords' length and store the website and password details in a text file. This project will not use encryption algorithms, databases, cloud storage, or account storage.

## THE TARGET AUDIENCE
The application will be designed to address the needs of the end-users. They include users who want to manage their website passwords. This project will also satisfy the needs of students and new developers who intend to learn how to develop applications to manage passwords using Java. The project will also help students learn Java OOPs concepts such as classes, objects, inheritance, abstraction, encapsulation, interfaces, method overloading, method overriding, and exception handling. Additionally, students will learn how to perform file handling and storage operations.

## THE MAIN FEATURES
The Password Security Manager will have the following features:
1. Collect the user's name and email address.
2. Collect the website name and password.
3. Display the user's name and password details.
4. Determine the type of password that the user has entered.
5. Calculate and display the strength of the password. The strength level includes strong, moderate, and weak.
6. The application will check if the password is sufficient.
7. Storing the website name and password in a text file.
8. Exception handling when storing the data into a file.
9. The application will be developed using java classes so that different components can be put together in different classes.
